# 目录比对与目录内去重

## 背景

用户有一个整理好的目录 A 和一个混乱的目录 B。B 中混有 A 已有的照片/视频（可能一份或多份副本，散落在不同子目录）。需要可靠地把 B 中"与 A 内容完全一致"的文件移入回收站。另外需要一个独立的"目录内去重"页面，处理单个目录内跨子目录的重复副本。两个页面必须共用同一套扫描与校验函数。

用户核心约束：**校验必须绝对准确，不能出现校验值一样但实际是不同照片/视频的情况。**

## 需求

### R1 目录比对页（新页面）
- 选择目录 A（保留库，只读，绝不修改/删除 A 中任何文件）与目录 B（待清理）。
- 递归扫描 A 和 B 的全部子目录。
- 找出 B 中所有与 A 中某文件内容逐字节一致的文件；B 中同一内容有多份副本时**全部**列为回收对象。
- B 内部互相重复、但 A 中没有的文件：本页不处理。
- 结果表格每行：B 缩略图、A 缩略图、B 文件路径、对应 A 文件路径、大小、修改时间、SHA-256、状态；行可勾选，默认勾选全部"已确认一致"的行。
- 只移入回收站（send2trash），不提供永久删除。

### R2 目录内去重页（新页面，独立于现有"去重"页）
- 选择一个目录，递归扫描全部子目录。
- 按内容（逐字节一致）分组，每组保留 1 个文件，其余列为回收对象。
- 保留策略：层级最浅/路径最短（默认）、修改时间最早、修改时间最新；平手按路径排序，结果确定可复现。
- 结果表格每行：组号、缩略图、角色（保留/重复）、路径、大小、修改时间、SHA-256、状态；同组行视觉上可区分（分组底色交替）。
- 保留行不可勾选；重复行默认全勾，可取消。
- 只移入回收站。

### R3 共用扫描/校验核心（准确性）
- 两个页面调用同一个 Qt 无关的核心模块，不得各自实现扫描或哈希。
- 判定"一致"的唯一依据：**大小相同 + 完整文件 SHA-256 相同 + 与参照文件逐字节比对完全相同**，三者缺一不可。
- SHA-256 相同但逐字节不同 → 标记"校验不一致"，绝不回收，单独计数展示。
- 读取失败、权限不足、扫描中消失的文件 → 记录为问题项，绝不回收。
- 执行回收前对每一对（目标, 参照/保留文件）重新校验：两者都存在、大小与 mtime 与扫描时一致；"执行前再次逐字节复核"（默认开启）时再逐字节比对一次。任一不满足 → 跳过并给出原因。
- 任何情况下不回收参照文件/保留文件；每组至少保留一个文件。

### R4 安全边界
- 目录比对：A 与 B 相同、A 在 B 内、B 在 A 内（解析真实路径后判断）→ 拒绝扫描并提示。
- 不跟随符号链接 / 目录联接（junction）/ 其他重解析点。
- 默认跳过 0 字节文件。
- 扫描范围："所有文件"（默认）或"仅照片/视频"。

### R5 缩略图与预览
- 表格中显示缩略图（照片、视频都要有图；HEIC/视频依赖系统缩略图能力，拿不到时显示按类型区分的占位图）。
- 缩略图异步加载、只加载可见行、带缓存，不阻塞扫描与界面。
- 选中一行时，侧边预览面板显示较大预览：比对页并排显示 B 与对应 A；去重页显示该文件与本组保留文件。预览面板下方显示完整路径、大小、mtime。

### R6 右键菜单与打开
- 右键菜单：打开文件、打开所在目录（资源管理器中选中该文件）、复制路径；比对页额外：打开对应 A 文件、打开 A 文件所在目录；去重页额外：打开本组保留文件所在目录。
- 双击行打开文件（系统默认程序）。
- 复用项目现有 `file_context_menu.py` 能力，不另起一套。

### R7 体验
- 扫描、哈希、比对、回收全部在后台线程，界面不冻结；扫描可停止；回收可暂停/停止。
- 进度显示当前阶段（枚举文件 / 计算哈希 / 逐字节复核 / 回收）与进度。
- 执行前确认对话框显示将回收的文件数与总大小。
- 完成后汇总：已回收、跳过（含原因）、失败、校验不一致、读取问题数量。
- 中英文界面，接入 unified_gui 导航，语言切换生效。

## 验收标准

- [ ] AC1 B 中某 A 文件存在 3 份副本（不同子目录、不同文件名）→ 3 份全部列为回收对象并被回收，A 原文件不动。
- [ ] AC2 同大小、不同内容的文件不被判为重复（含仅末尾 1 字节不同的大文件）。
- [ ] AC3 测试中 monkeypatch 哈希使两文件 SHA-256 "相同"但内容不同 → 结果为"校验不一致"，不回收。
- [ ] AC4 扫描后、执行前修改目标或参照文件（内容/大小/mtime）→ 该项跳过。
- [ ] AC5 扫描后删除参照/保留文件 → 对应目标项跳过。
- [ ] AC6 A/B 相同或互相嵌套 → 拒绝扫描。
- [ ] AC7 目录内去重每组恰好保留 1 个文件，保留策略生效且确定可复现。
- [ ] AC8 无读权限/被占用文件进入问题列表，不崩溃、不回收。
- [ ] AC9 两个新页面出现在 unified_gui 导航，中英文切换正常，扫描/回收中界面可响应。
- [ ] AC10 缩略图在表格与预览面板中显示（照片至少经 Qt 回退能出图；拿不到时显示占位图），滚动不卡顿。
- [ ] AC11 右键菜单各项可用，"打开所在目录"在资源管理器中选中该文件；双击打开文件。
- [ ] AC12 核心模块单元测试全部通过（stdlib unittest，无新依赖）。

## 不在范围内

- 不修改、不替换现有"去重"页（dedupe_media_gui.py）；是否合并由用户后续决定。
- 不做相似图片/视觉相似度去重，只做字节级完全一致。
- 不提供永久删除、不提供"移动到其他目录"。
- 不做 CSV 导出。
- 不新增第三方依赖。
